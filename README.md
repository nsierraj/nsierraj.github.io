# nsierraj.github.io

Personal blog, built with Jekyll and served via GitHub Pages at https://nsierraj.github.io.

## Local development

```
bundle install
bundle exec jekyll serve
```

Site will be available at http://localhost:4000.

## New post

Add a file to `_posts/` named `YYYY-MM-DD-title.markdown` with front matter:

```
---
layout: post
title:  "Post title"
date:   YYYY-MM-DD HH:MM:SS -0000
categories: general
---
Post content here.
```
